# Simple Calculator Web App

A clean, responsive web application that performs basic arithmetic operations based on user input. 

This project was built as part of an HTML, CSS, and JavaScript learning module to practice DOM manipulation, event handling, and UI design.

---

## 🚀 Features

* **User Input:** Accept two numerical values from the user.
* **Operation Selection:** Choose arithmetic operations (`+`, `-`, `*`, `/`) via a custom dropdown menu.
* **Dynamic Result Display:** Calculate and display results instantly upon clicking the calculate button.
* **Clean UI:** Responsive layout styled with modern CSS principles.

---

## 🛠️ Tech Stack

* **HTML5** – Page structure and form elements
* **CSS3** – Layout, styling, and visual feedback
* **JavaScript (ES6+)** – Core logic, DOM manipulation, and input validation
